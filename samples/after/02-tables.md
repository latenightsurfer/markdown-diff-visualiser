# Feature Matrix

The table below compares the supported comparison modes.

| Mode                  | Left side | Right side   | Default |
| --------------------- | --------- | ------------ | :-----: |
| Committed vs Unstaged | HEAD      | Working tree |   yes   |
| Committed vs Staged   | HEAD      | Staging area |   no    |
| Staged vs Unstaged    | Index     | Working tree |   no    |
| Commit                | Parent    | Commit       |   no    |

## Supported platforms

| Platform | Status       |
| -------- | ------------ |
| Windows  | tested       |
| macOS    | tested       |
| Linux    | tested       |
| WSL      | experimental |

## Keyboard shortcuts

| Action       | Default shortcut |
| ------------ | ---------------- |
| Show changes | Ctrl+Alt+D       |
| Next change  | Alt+Down         |
